# Trip-advisory
A responsive Tripadvisor-inspired travel website built using HTML and CSS, featuring a navigation bar, search section, travel categories, restaurant cards, and responsive design.
Tripadvisor Website 

A Tripadvisor-inspired travel website created using HTML and CSS. This project focuses on recreating a modern travel platform layout with a clean design, responsive navigation, search functionality, travel categories, restaurant recommendations, and a footer section.

Project Overview

This project is a frontend practice project developed to improve my skills in HTML, CSS, Flexbox, responsive design, and UI development.

The website includes a Tripadvisor-style homepage where users can explore travel categories, search for destinations, view recommended restaurants, and access different sections through the navigation and footer.

Features
Tripadvisor-style navigation bar
Search bar for places, hotels, restaurants, and activities
Travel category navigation
Restaurant recommendation section
Restaurant ratings
Travel and restaurant images
Responsive design for smaller screens
Responsive navigation menu
Footer with useful links
Currency and country selection
Social media icons using Font Awesome
Hover effects on interactive elements
